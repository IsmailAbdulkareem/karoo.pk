Karoo is a service booking app for Pakistan's informal economy. 
Users book plumbers, electricians, tutors via AI chat, browsing, 
or open requests. Providers accept AI bookings or pick open jobs.
Single FastAPI backend serves both roles via JWT role field.
Database: Supabase. AI: Gemini + Antigravity + MCP tools.
Mobile + Web: Expo React Native with NativeWind.
